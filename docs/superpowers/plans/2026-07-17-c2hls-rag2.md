# c2hls RAG2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (or implement task-by-task). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add opt-in RAG2 — dual BM25 indexes (opt vs repair), structured hybrid queries, CLI/env, wiring in flash/repair/dataflow, and `rag2_skills` / `rag2_ns` DeepSeek flavors — without changing scrape/BM25 or the running DeepSeek sequence.

**Architecture:** New `c2hls_rag2.py` builds deterministic queries (LLM keyword fallback if empty), ranks via exported BM25 helpers from `c2hls_rag.py` against `artifacts/rag/rag2_{opt,repair}/`. Call sites prefer RAG2 over scrape/BM25 when `C2HLS_RAG2=1`. Build script materializes indexes from `knowledge_repo` PDFs.

**Tech Stack:** Python 3, existing BM25 in `c2hls_rag.py`, `pypdf` for index build, pytest, bash campaign starters.

**Spec:** `docs/superpowers/specs/2026-07-17-c2hls-rag2-design.md`
