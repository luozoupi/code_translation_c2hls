\subsection*{Column definitions (win metrics)}

All win columns are computed \textbf{per benchmark} over the \textbf{full pool of 49 flash runs}
(27 scored kernels; \texttt{doitgen} excluded). \textbf{Lower synthesis latency (cycles) is better.}
These metrics compare flash runs to each other; they are \textbf{not} vs ground truth.

\begin{description}
  \item[\textbf{Abs}] (\emph{absolute win})
    Count of benchmarks where this variant had the \textbf{sole} lowest final csynth latency
    among all runs (no other run tied within 0.1\%).
  \item[\textbf{Shared}] (\emph{shared win})
    Count of benchmarks where this variant \textbf{tied} for lowest latency with at least one
    other run (within 0.1\% of the minimum). Tied benchmarks award no Abs win to any party.
  \item[\textbf{Pooled}] (\emph{pooled / fractional win score})
    $\text{Abs} + \sum_{\text{tied benches}} 1/n$, where $n$ is the number of runs tied at the
    minimum on that bench (e.g.\ sole win $=1.0$; two-way tie $=0.5$ each; three-way $=0.33$ each).
    Maximum possible $=27$.
\end{description}

\noindent\textbf{Geo-mean} $=$ geometric mean of (generated latency / ground-truth latency); lower is better.
\textbf{Spd} $= 1/\textbf{Geo}$ $=$ geo-mean (GT / synth); higher is better.
\textbf{F$<$GT} / \textbf{F$>$GT} $=$ count of benchmarks with ratio $<1$ / $>1$.
One row per variant (best geo-mean stamp). \textbf{Sk} $=$ skills in library file; \textbf{Inj} $=$ skills injected into prompt (U280-filtered; ``cur.'' = LLM-curated subset).
New libraries: \texttt{skills\_ii\_target\_miss\_solutions\_added(73skills).json} (73 entries, 57 positive injected);
\texttt{skills\_ii\_target\_miss\_solutions\_added(90skills).json} (90 entries, 66 positive / 90 all injected).
