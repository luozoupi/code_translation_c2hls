\section*{Executive summary}

Full-corpus multistep pipelined runs on \textbf{28} HLSFactory \texttt{benchmarks\_cosim} kernels
(Xilinx \texttt{xcu280-fsvh2892-2L-e}, 4\,ns target clock). Workflow per benchmark:
Phase~A (C$\rightarrow$HLS reference validation), Phase~B (initial HLS translate + csynth/csim),
then five sequential single-technique optimization steps:
\emph{coalescing}, \emph{tiling}, \emph{pipeline}, \emph{unroll}, \emph{doublebuffer}.
\textbf{RTL cosim was not executed} (csynth + csim only).
LLM: \texttt{mistralai/Devstral-2-123B-Instruct-2512}.
Pipelined runner with 4 synth workers; GPU session + compute node.

\begin{itemize}
  \item \textbf{nav\_n}: 90-skill library, all skills injected, \emph{no avoids}.
  \item \textbf{noskills}: skills disabled (LLM-only multistep baseline).
  \item \textbf{aav\_n} (90 skills + avoids): full corpus submitted separately; results pending at report time.
\end{itemize}

Both completed campaigns reported here: \textbf{26/28 OK}, \textbf{2 failures} each.
Selected result = lowest-latency successful step among phase\_b and the five optimization steps.
